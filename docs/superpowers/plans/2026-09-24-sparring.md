# Stück 3 – Sparring

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Auf Knopfdruck spielt die Bridge im Hintergrund N Partien 1vs1 mit einem Deck gegen zufällige Gegner aus demselben Bracket und füllt damit die Statistik.

**Architecture:** Bracket als drittes Deck-Tag (aus Archidekt oder von Hand), Gegnerwahl als reine Funktion, Lauf über Kindprozesse (`Main --sparring-one`) wie der Bench, Fortschritt per `sparringProgress`, Bedienung im Statistik-Board. Spec: `docs/superpowers/specs/2026-09-24-sparring-design.md`.

**Tech Stack:** Java 21 (Bridge, JUnit 5), Forge, React 18/TS/Vitest/Playwright.

### Task 2: Gegnerwahl und Lauf

**Files:** Create `bridge/src/main/java/mtgplayer/sparring/SparringOpponents.java`, `SparringRun.java`, `SparringArgs.java`; Modify `bridge/src/main/java/mtgplayer/Main.java` (`--sparring-one`), `bridge/src/main/java/mtgplayer/protocol/Messages.java`, `bridge/src/main/java/mtgplayer/server/Bridge.java`; Tests `SparringOpponentsTest`, `SparringRunTest`, `BridgeEndToEndTest`

**Interfaces:**
```java
public record SparringArgs(String deck, int games, AiConfig ai, int timeout, int maxTurns) { }
public final class SparringOpponents {
    /** Kandidaten nach Spec §2; wirft IllegalArgumentException, wenn keine uebrig bleiben. */
    public static List<String> candidates(DeckStore store, String deck);
    /** Zieht je Partie einen Gegner (gleichverteilt, mit Zuruecklegen). */
    public static List<String> draw(List<String> candidates, int games, java.util.Random rnd);
}
public interface GameRunner { MatchRecord play(SparringArgs args, String opponent, long seed); }  // Kindprozess bzw. Attrappe im Test
public final class SparringRun {
    public SparringRun(DeckStore store, MatchStore matches, GameRunner runner, Consumer<Object> out);
    public void start(SparringArgs args);   // Hintergrund-Thread; zweiter Start -> IllegalStateException
    public void cancel();
    public boolean running();
}
// Messages
public record SparringProgress(String type, int done, int total, String current, List<String> errors, boolean running) { … }
```
`Main --sparring-one <json SparringArgs + opponent + seed>`: eine Partie über `AiMatch.play(..., sink)`, Ergebnis als `SPARRING_RESULT <json MatchRecord>` auf stdout. Der Kindprozess-Runner erbt das Muster von `mtgplayer.bench.SubprocessRunner` (Klassenpfad, `-Xmx4g`, Ausgabe zeilenweise lesen, Zeitlimit) – gemeinsame Teile wiederverwenden statt kopieren.
`Bridge`: `case "sparringStart"` → `SparringRun.start`, Fehler → `error`; `case "sparringCancel"` → `cancel()`. Nach jedem Datensatz `matches` senden.
