# Bench: Forge 2.0.14 gegen 2.0.15

Datum: 2026-10-06. Anlass: Entscheidungsgrundlage für den Fassungswechsel
(`docs/superpowers/specs/2026-10-06-forge-fassungswechsel-design.md`, §5 und §6).

## Aufbau

Der Bench vergleicht zwei KI-Einstellungen **innerhalb** einer Engine; zwei Engines kann er nicht
gegeneinander spielen lassen. Der Vergleich entsteht deshalb aus **zwei Läufen mit demselben Startwert**,
die sich ausschließlich in `-Dforge.version` unterscheiden. Decks, Profile, Partienzahl und Bedenkzeit
sind gleich, und derselbe Startwert erzeugt in beiden Läufen dieselben Partien.

- Paarung: `sim:Default` (A) gegen `standard:Default` (B)
- Decks: A = precon Abzan Armor [TDC], B = precon Adaptive Enchantment [C18]
- 40 Partien, Zugdeckel 200, Bedenkzeit 5 s, Startwert `20261006`
- Kartendaten in beiden Läufen identisch (`bridge/assets/res` des Hauptbaums)

## Ergebnis

| | 2.0.14 (Kontrolle) | 2.0.15 |
|---|---|---|
| Siege A : B | 37 : 3 | 37 : 3 |
| Siegquote A | 92,5 % | 92,5 % |
| 95-%-Intervall | 80,1–97,4 % | 80,1–97,4 % |
| Ø Züge (Median) | 16,6 (15) | 16,4 (14) |
| Ø Dauer je Partie | 33 s | 31 s |
| Abstürze | 0 | 0 |
| Simulation defekt | 0 | 0 |
| Unentschieden / Zugdeckel | 0 / 0 | 0 / 0 |

## Paarweiser Vergleich

Aussagekräftiger als die Quote, weil beide Läufe dieselben Partien spielen:

- **34 von 40 Partien identisch** (gleicher Sieger, gleiche Zugzahl)
- **6 Partien mit gleichem Sieger, aber anderer Zugzahl** — die Engines spielen also nachweislich anders
- **0 Partien mit anderem Sieger**

Die Verhaltensänderung ist real, hat aber in keiner Partie das Ergebnis gedreht.

## Einordnung

Vierzig Partien tragen eine Unsicherheit von gut fünfzehn Prozentpunkten. Das fängt einen **Absturz** der
Spielstärke, keine Feinheit. Eine Verschiebung von fünf Punkten sicher zu sehen, bräuchte Hunderte von
Partien; das war ausdrücklich nicht Teil dieser Arbeit.

Die identische Quote ist deshalb **kein** Beleg dafür, dass beide Engines gleich stark sind — sie belegt,
dass 2.0.15 in dieser Paarung nicht eingebrochen ist. Der paarweise Vergleich stützt das zusätzlich: wäre
die neue Engine deutlich schwächer, hätte mindestens eine der sechs abweichenden Partien kippen müssen.

## Entscheidung

Die Regel stand vor der Messung fest (§6): Fehlschlag nur, wenn die neue Fassung **klar unter** der
Kontrollseite liegt, also unterhalb deren unterer Schranke von 80,1 %. Sie liegt mit 92,5 % exakt
gleichauf.

**Ergebnis: der Wechsel wird übernommen.**
